# Contributing to DuoDesk

> [!IMPORTANT]
> **DuoDesk is in a feature freeze.** We are not adding new features until all current bugs and performance problems are fixed.
> Bug reports, performance reports and fixes for them are very welcome. Feature requests and feature PRs will be closed or left for after the freeze.

## Reporting a bug

Open an issue at [github.com/0xCodez/DuoDesk/issues](https://github.com/0xCodez/DuoDesk/issues). Please include your OS and version, the DuoDesk version, which devices were connected and the steps to reproduce. Logs and screenshots help a lot.

To find the logs, choose **Open Log Folder** in DuoDesk's menu bar or tray menu, or **Open log folder** under About. Attach `DuoDesk.log`, and `crash.log` if there is one, from each computer involved.

## Pull requests

Open pull requests against [0xCodez/DuoDesk](https://github.com/0xCodez/DuoDesk). During the freeze, only bug fixes and performance fixes will be merged. Keep each PR to one fix and say which issue it fixes.
